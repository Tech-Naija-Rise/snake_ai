# Neural Network Snake Game
This is a snake game that plays itself. It is basically like giving a snake a brain.

## How to train

Just run `train.py`. Interrupt it with Ctrl+C. It will save the weights to be loaded by `play.py`.

## How to run game

Just run `play_with_map.py` or `play.py`.
